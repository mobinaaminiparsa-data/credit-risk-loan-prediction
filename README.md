# Credit Risk Modeling and Loan Approval Prediction using Decision Trees

## Project Overview
This project develops a machine learning model to predict loan approval decisions based on applicants’ financial and demographic information.

## Objectives
- Perform exploratory data analysis on credit data
- Identify key risk indicators
- Build an interpretable classification model
- Reduce overfitting using cost-complexity pruning

## Methods
- Data Preprocessing and Feature Engineering
- Exploratory Data Analysis (EDA)
- Decision Tree Classification
- Cost-Complexity Pruning
- Cross Validation
- Model Performance Evaluation (Accuracy, Precision, Recall, F1-score)

## Key Findings
- Identification of important predictors affecting loan approval
- Improved generalization after pruning
- Clear decision boundaries enabling interpretability

## Tools & Libraries
- Python
- Pandas
- Scikit-learn
- Matplotlib

## Business Insight
This model can support financial institutions in improving credit decision processes while maintaining interpretability and reducing risk.
